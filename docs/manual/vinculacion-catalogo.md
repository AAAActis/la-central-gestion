# Vincular catálogo · buscar un repuesto en los catálogos de los proveedores

1. Entrá a **Vincular catálogo**. Escribí un código, un número original o un nombre y apretá **Buscar**
   (o Enter). Mientras busca, el botón dice «Buscando…».
2. Arriba están las **coincidencias exactas**. Para comparar, no cuentan los separadores, las mayúsculas
   ni los acentos: «GN/100» y «gn 100» son lo mismo. Se compara contra el código, el número original, el
   código de barras y el nombre de cada fila.
3. Abajo, aparte, están las coincidencias **por aproximación**, ordenadas de la más parecida a la menos
   parecida, con el porcentaje de parecido. Solo aparecen las que llegan al umbral configurado (0,3 por
   ahora; se ajusta cuando se mida con datos reales).
4. Si una fila ya está vinculada a un artículo propio, la columna **Vinculación** dice a cuál, con su
   código interno. Las demás dicen «Sin vincular».
5. No aparecen las filas de proveedores dados de baja ni los productos vencidos.
6. Si nada coincide, la pantalla dice «No hay candidatos para «…»» con el texto que buscaste.

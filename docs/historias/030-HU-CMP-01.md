## 1 · Historia

**Como** Vendedor  
**Quiero** buscar un artículo por su nombre y ver en una sola pantalla lo que cuesta en cada proveedor  
**Para** saber cuál conviene sin tener que abrir la página de cada proveedor por separado

## 2 · Precondiciones

El artículo tiene al menos un código alternativo asociado a un proveedor activo (HU-ART-01)

## 3 · Criterios de aceptación

| ID | Dado que | Cuando | Entonces | Tipo | Prueba |
|---|---|---|---|---|---|
| **CA-001** | Dado que el artículo tiene varios proveedores asociados | cuando el vendedor lo selecciona | entonces el sistema muestra cada proveedor con el código que le asigna y su precio | + | Pendiente |
| **CA-002** | Dado que se muestran los proveedores de un artículo | cuando se despliega el resultado | entonces el sistema los ordena por precio ascendente, con la opción más barata primero | + | Pendiente |
| **CA-003** | Dado que el artículo tiene un único proveedor asociado | cuando el vendedor lo selecciona | entonces el sistema lo muestra igualmente, sin comparación | + | Pendiente |
| **CA-004** | Dado que el artículo no tiene ningún proveedor asociado | cuando el vendedor lo selecciona |  | − | Pendiente |
| **CA-005** | Dado que uno de los proveedores del artículo está dado de baja | cuando se despliega la comparación | entonces el sistema no lo incluye entre los resultados | − | Pendiente |

**Cantidad de criterios: 5.**

## 4 · Notas

Funcionalidad de innovación del proyecto. Depende íntegramente del modelo de códigos alternativos por proveedor.

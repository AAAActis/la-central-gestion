## 1 · Historia

**Como** Vendedor  
**Quiero** reactivar un cliente dado de baja  
**Para** volver a operar con él sin tener que cargar sus datos de nuevo

## 2 · Precondiciones

El cliente existe en estado inactivo (HU-CLI-04)

## 3 · Criterios de aceptación

| ID | Dado que | Cuando | Entonces | Tipo | Prueba |
|---|---|---|---|---|---|
| **CA-001** | Dado que el cliente está inactivo | cuando el vendedor busca habilitando la opción de incluir inactivos | entonces el sistema lo devuelve entre los resultados, marcado como inactivo | + | Pendiente |
| **CA-002** | Dado que el vendedor localizó el cliente inactivo | cuando el vendedor confirma la reactivación | entonces el sistema lo marca como activo y queda disponible para nuevas facturas | + | Pendiente |
| **CA-003** | Dado que el cliente fue reactivado | cuando se consulta su ficha | entonces el sistema conserva y muestra el motivo de la baja anterior | + | Pendiente |
| **CA-004** | Dado que el cliente ya está activo | cuando el vendedor intenta reactivarlo | entonces el sistema no ofrece la opción de reactivación | − | Pendiente |

**Cantidad de criterios: 4.**

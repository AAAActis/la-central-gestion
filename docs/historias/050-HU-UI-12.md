## 1 · Historia

**Como** Vendedor  
**Quiero** ver en una sola pantalla los precios de todos los proveedores de un artículo  
**Para** decidir a quién comprarle o a cuánto vender sin consultar cada sitio por separado

## 2 · Precondiciones

HU-CMP-01 a HU-CMP-05 disponibles en la API

## 3 · Criterios de aceptación

| ID | Dado que | Cuando | Entonces | Tipo | Prueba |
|---|---|---|---|---|---|
| **CA-001** | Dado que el usuario busca un artículo por nombre | cuando selecciona uno de los resultados | entonces el sistema muestra los proveedores ordenados por precio ascendente | + | Pendiente |
| **CA-002** | Dado que algunas consultas ya respondieron y otras siguen en curso | cuando se está cargando el resultado | entonces el sistema muestra los precios que ya llegaron sin esperar a los demás | + | Pendiente |
| **CA-003** | Dado que la consulta a un proveedor falló | cuando se completa la búsqueda | entonces el sistema lo informa y muestra su último precio conocido con la fecha en que se obtuvo | − | Pendiente |
| **CA-004** | Dado que el usuario alterna entre vista de compra y de venta | cuando cambia la selección | entonces el sistema muestra en la de venta el precio estimado propio y la existencia por sucursal | + | Pendiente |
| **CA-005** | Dado que el proveedor no tiene URL de referencia cargada | cuando se muestra el resultado | entonces el sistema no ofrece la opción de abrir su sitio para ese proveedor | − | Pendiente |

**Cantidad de criterios: 5.**

## 4 · Notas

La visualización progresiva no es un detalle estético: es lo que hace usable el comparador mientras el vendedor atiende al cliente en el mostrador.

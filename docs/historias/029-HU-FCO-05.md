## 1 · Historia

**Como** Encargado de Administración  
**Quiero** cargar una factura de compra subiendo el PDF del proveedor y revisando lo interpretado  
**Para** no tener que tipear campo por campo y reducir los errores de digitación

## 2 · Precondiciones

Existen artículos con códigos alternativos por proveedor (HU-ART-01) · Existe el padrón de proveedores (HU-PRO-01) · El usuario dispone del archivo PDF

## 3 · Criterios de aceptación

| ID | Dado que | Cuando | Entonces | Tipo | Prueba |
|---|---|---|---|---|---|
| **CA-001** | Dado que el archivo es un PDF con texto extraíble | cuando el usuario lo adjunta | entonces el sistema extrae proveedor, número de factura, fechas, retenciones y líneas de detalle, y las presenta en un formulario editable | + | Pendiente |
| **CA-002** | Dado que el archivo no es PDF o es un PDF escaneado sin texto | cuando el usuario lo adjunta | entonces el sistema lo rechaza e indica que debe cargarse por la vía manual | − | Pendiente |
| **CA-003** | Dado que el sistema interpretó los datos del comprobante | cuando se muestra el formulario de revisión | entonces ningún dato se guarda hasta que el usuario confirma | + | Pendiente |
| **CA-004** | Dado que un código de producto no coincide con ningún artículo | cuando el sistema completa el cotejo | entonces marca la línea como no resuelta y ofrece la redirección al alta manual de artículo, sin crearlo por su cuenta | − | Pendiente |
| **CA-005** | Dado que quedan líneas con código no resuelto | cuando el usuario intenta confirmar la factura | entonces el sistema bloquea la confirmación hasta que se asocien, se den de alta o se quiten | − | Pendiente |
| **CA-006** | Dado que el usuario revisó y corrigió los datos | cuando el usuario confirma | entonces el sistema registra la factura con los mismos efectos que una carga manual y deja constancia de que se cargó por la vía automatizada | + | Pendiente |

**Cantidad de criterios: 6.**

## 4 · Notas

Nota técnica: de un PDF nativo el texto se extrae sin OCR. La interpretación asistida por IA aporta valor solo si el formato de factura varía entre proveedores; si son similares, un parser por reglas es más simple y predecible. Decisión pendiente del equipo: analizar facturas reales de varios proveedores — responsable Billarroel Lautaro.

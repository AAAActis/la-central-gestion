## 1 · Historia

**Como** Encargado de Administración  
**Quiero** corregir ciertos datos administrativos de una factura de compra cargada  
**Para** arreglar errores de carga sin anularla y rehacerla

## 2 · Precondiciones

La factura existe y está en estado activo

## 3 · Criterios de aceptación

| ID | Dado que | Cuando | Entonces | Tipo | Prueba |
|---|---|---|---|---|---|
| **CA-001** | Dado que la factura está activa | cuando el usuario modifica la ubicación de ingreso | entonces el sistema guarda el cambio | + | Pendiente |
| **CA-002** | Dado que la factura está activa | cuando el usuario intenta modificar los artículos del detalle | entonces el sistema no ofrece esa posibilidad | − | Pendiente |
| **CA-003** | Dado que la factura está activa | cuando el usuario intenta cambiar el proveedor | entonces el sistema deniega la operación | − | Pendiente |
| **CA-004** | Dado que la factura está anulada | cuando el usuario intenta modificarla | entonces el sistema deniega la operación | − | Pendiente |

**Cantidad de criterios: 4.**

## 4 · Notas

La ubicación es editable justamente porque no proviene del comprobante sino de una selección manual durante la carga (HU-STK-02).

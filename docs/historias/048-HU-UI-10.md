## 1 · Historia

**Como** Vendedor o encargado de compras  
**Quiero** registrar y consultar facturas de venta y de compra  
**Para** asentar las operaciones diarias del negocio

## 2 · Precondiciones

HU-UI-04 y HU-UI-05 implementadas · Épicas 5 y 6 disponibles en la API

## 3 · Criterios de aceptación

| ID | Dado que | Cuando | Entonces | Tipo | Prueba |
|---|---|---|---|---|---|
| **CA-001** | Dado que el usuario carga líneas de detalle | cuando agrega o modifica una | entonces el sistema recalcula el total en pantalla sin permitir editarlo manualmente | + | Pendiente |
| **CA-002** | Dado que el usuario busca un artículo para agregarlo | cuando ingresa nombre o cualquier código | entonces el sistema lo localiza y lo incorpora al detalle | + | Pendiente |
| **CA-003** | Dado que la venta supera la existencia de la sucursal seleccionada | cuando se carga la línea | entonces el sistema informa la situación y, si la otra sucursal dispone del faltante, lo indica, permitiendo continuar | + | Pendiente |
| **CA-004** | Dado que la factura no tiene ninguna línea | cuando el usuario intenta confirmar | entonces el sistema bloquea la operación | − | Pendiente |
| **CA-005** | Dado que el usuario anula una factura | cuando confirma la operación | entonces el sistema muestra el resultado de la reversión de existencias y precios | + | Pendiente |

**Cantidad de criterios: 5.**

## 4 · Notas

Comparten componentes con distinto comportamiento de stock: la compra suma, la venta resta y admite negativo.

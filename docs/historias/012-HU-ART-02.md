## 1 · Historia

**Como** Vendedor  
**Quiero** buscar un artículo por su nombre o por cualquiera de sus códigos  
**Para** encontrarlo sin importar con qué código lo nombre el proveedor o el cliente

## 2 · Precondiciones

Existen artículos cargados con sus códigos alternativos (HU-ART-01)

## 3 · Criterios de aceptación

| ID | Dado que | Cuando | Entonces | Tipo | Prueba |
|---|---|---|---|---|---|
| **CA-001** | Dado que existen varios artículos cuyo nombre coincide parcialmente | cuando el vendedor busca por nombre | entonces el sistema devuelve todos los coincidentes | + | Pendiente |
| **CA-002** | Dado que existe un artículo con el código interno buscado | cuando el vendedor busca por código interno | entonces el sistema devuelve exactamente un artículo | + | Pendiente |
| **CA-003** | Dado que el código buscado es un código alternativo de un proveedor | cuando el vendedor lo ingresa en la búsqueda | entonces el sistema devuelve el artículo al que ese código pertenece | + | Pendiente |
| **CA-004** | Dado que el código buscado no existe en el sistema | cuando el vendedor ejecuta la búsqueda | entonces el sistema muestra el mensaje «sin resultados» | − | Pendiente |
| **CA-005** | Dado que el vendedor abre el detalle de un artículo | cuando se muestra la ficha | entonces el sistema despliega sus códigos alternativos con su proveedor, el último proveedor comprado, el precio de costo vigente y el precio de venta estimado | + | Pendiente |

**Cantidad de criterios: 5.**

## 4 · Notas

La búsqueda por código alternativo es la funcionalidad que sostiene el cotejo automático de facturas.

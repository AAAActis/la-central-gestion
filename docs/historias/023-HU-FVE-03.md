## 1 · Historia

**Como** Vendedor  
**Quiero** corregir ciertos datos administrativos de una factura ya cargada  
**Para** arreglar errores de carga sin tener que anularla y rehacerla

## 2 · Precondiciones

La factura existe y está en estado activo (HU-FVE-01)

## 3 · Criterios de aceptación

| ID | Dado que | Cuando | Entonces | Tipo | Prueba |
|---|---|---|---|---|---|
| **CA-001** | Dado que la factura está activa | cuando el vendedor modifica la ubicación de salida | entonces el sistema guarda el cambio | + | Pendiente |
| **CA-002** | Dado que la factura está activa | cuando el vendedor intenta agregar, quitar o modificar un artículo del detalle | entonces el sistema no ofrece esa posibilidad | − | Pendiente |
| **CA-003** | Dado que la factura está activa | cuando el vendedor intenta cambiar el cliente | entonces el sistema deniega la operación | − | Pendiente |
| **CA-004** | Dado que la factura está anulada | cuando el vendedor intenta modificarla | entonces el sistema deniega la operación | − | Pendiente |

**Cantidad de criterios: 4.**

## 4 · Notas

Los errores de detalle se corrigen anulando y volviendo a cargar (HU-FVE-04).

## 1 · Historia

**Como** Vendedor  
**Quiero** que el sistema calcule un precio de venta estimado a partir del costo y los márgenes  
**Para** tener una referencia rápida al momento de definir el precio al cliente

## 2 · Precondiciones

El artículo tiene márgenes cargados (HU-ART-01) y un precio de costo vigente (HU-FCO-01)

## 3 · Criterios de aceptación

| ID | Dado que | Cuando | Entonces | Tipo | Prueba |
|---|---|---|---|---|---|
| **CA-001** | Dado que el artículo tiene márgenes cargados y una factura de compra actualiza su precio de costo | cuando se confirma esa factura | entonces el sistema recalcula el precio de venta estimado de ese artículo | + | Pendiente |
| **CA-002** | Dado que se recalcula el precio estimado de un artículo | cuando se consultan otros artículos del catálogo | entonces el sistema no modifica ninguno de ellos | + | Pendiente |
| **CA-003** | Dado que el artículo no tiene márgenes cargados | cuando se actualiza su precio de costo | entonces el sistema no calcula precio estimado y lo indica en la ficha | − | Pendiente |
| **CA-004** | Dado que el sistema muestra un precio de venta estimado | cuando el vendedor registra una factura de venta | entonces el sistema permite ingresar un precio distinto: el estimado es una referencia, no un valor impuesto | + | Pendiente |

**Cantidad de criterios: 4.**

## 4 · Notas

Márgenes definidos por el equipo: el margen de 0% representa un precio de venta igual al de costo. Los márgenes de 50% y 40% son parte del sistema. Son constantes y se aplican siempre.

## 1 · Historia

**Como** Vendedor  
**Quiero** consultar las facturas de venta registradas  
**Para** verificar operaciones pasadas y responder consultas de clientes

## 2 · Precondiciones

Existen facturas de venta registradas (HU-FVE-01)

## 3 · Criterios de aceptación

| ID | Dado que | Cuando | Entonces | Tipo | Prueba |
|---|---|---|---|---|---|
| **CA-001** | Dado que existe una factura con el número buscado | cuando el vendedor busca por número | entonces el sistema devuelve exactamente una | + | Pendiente |
| **CA-002** | Dado que el cliente tiene varias facturas | cuando el vendedor busca por cliente | entonces el sistema devuelve la lista completa de sus facturas | + | Pendiente |
| **CA-003** | Dado que el vendedor define un rango de fechas | cuando se ejecuta la búsqueda | entonces el sistema devuelve solo las facturas comprendidas en ese rango | + | Pendiente |
| **CA-004** | Dado que no hay facturas que coincidan con el criterio | cuando se ejecuta la búsqueda | entonces el sistema muestra el mensaje «sin resultados» | − | Pendiente |
| **CA-005** | Dado que existen facturas anuladas entre los resultados | cuando se consulta el listado | entonces el sistema las muestra marcadas explícitamente como anuladas | + | Pendiente |

**Cantidad de criterios: 5.**

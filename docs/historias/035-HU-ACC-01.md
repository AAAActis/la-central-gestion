## 1 · Historia

**Como** Usuario del sistema  
**Quiero** iniciar sesión con las credenciales de mi puesto de trabajo  
**Para** acceder a las funciones del sistema y que mis operaciones queden registradas

## 2 · Precondiciones

El usuario fue dado de alta por el Administrador (HU-ACC-02)

## 3 · Criterios de aceptación

| ID | Dado que | Cuando | Entonces | Tipo | Prueba |
|---|---|---|---|---|---|
| **CA-001** | Dado que las credenciales son correctas y el usuario está activo | cuando el usuario inicia sesión | entonces el sistema le da acceso a las funciones operativas | + | Pendiente |
| **CA-002** | Dado que la contraseña ingresada es incorrecta | cuando el usuario intenta iniciar sesión | entonces el sistema muestra un mensaje genérico que no revela si falló el usuario o la contraseña | − | Pendiente |
| **CA-003** | Dado que el usuario fue dado de baja | cuando intenta iniciar sesión con credenciales correctas | entonces el sistema deniega el acceso | − | Pendiente |
| **CA-004** | Dado que el usuario falló varias veces consecutivas | cuando vuelve a intentar | entonces el sistema permite el nuevo intento: no hay bloqueo por intentos fallidos | + | Pendiente |
| **CA-005** | Dado que un usuario con rol Operador inició sesión | cuando accede al menú | entonces el sistema no muestra la opción de gestión de usuarios | − | Pendiente |

**Cantidad de criterios: 5.**

## 4 · Notas

Las contraseñas se almacenan cifradas y no son visibles ni recuperables desde ninguna pantalla, ni siquiera para el Administrador. Sin bloqueo por intentos fallidos, por decisión del equipo.

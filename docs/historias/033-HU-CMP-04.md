## 1 · Historia

**Como** Vendedor  
**Quiero** ver los precios de referencia junto al precio de venta estimado propio  
**Para** decidir a cuánto vender el artículo al cliente

## 2 · Precondiciones

El comparador devolvió resultados (HU-CMP-01) · El artículo tiene precio de venta estimado (HU-ART-05)

## 3 · Criterios de aceptación

| ID | Dado que | Cuando | Entonces | Tipo | Prueba |
|---|---|---|---|---|---|
| **CA-001** | Dado que el artículo tiene precio de venta estimado calculado | cuando se muestra la vista Venta | entonces el sistema lo despliega junto a los precios de los proveedores | + | Pendiente |
| **CA-002** | Dado que el vendedor consulta la vista Venta | cuando se registra luego una factura de venta | entonces el sistema permite ingresar un precio distinto del estimado | + | Pendiente |
| **CA-003** | Dado que el artículo tiene existencias registradas | cuando se muestra la vista Venta | entonces el sistema despliega la disponibilidad por ubicación para saber si hace falta comprarlo | + | Pendiente |
| **CA-004** | Dado que el artículo no tiene márgenes cargados | cuando se muestra la vista Venta | entonces el sistema indica que no hay precio estimado disponible | − | Pendiente |

**Cantidad de criterios: 4.**

## 4 · Notas

El sistema no impone ni modifica el precio de venta: la vista es de consulta y la decisión queda en el vendedor (Mandato v4).

## 1 · Historia

**Como** Usuario del sistema  
**Quiero** contar con una pantalla principal desde la que acceder a todas las funciones  
**Para** moverme entre módulos sin perder el contexto de mi trabajo

## 2 · Precondiciones

La API expone los endpoints de autenticación (HU-ACC-01) · El proyecto Angular está inicializado

## 3 · Criterios de aceptación

| ID | Dado que | Cuando | Entonces | Tipo | Prueba |
|---|---|---|---|---|---|
| **CA-001** | Dado que el usuario inició sesión | cuando accede a la aplicación | entonces el sistema muestra el menú con los módulos habilitados para su rol | + | Pendiente |
| **CA-002** | Dado que el usuario tiene rol Operador | cuando se despliega el menú | entonces el sistema no muestra la opción de gestión de usuarios | − | Pendiente |
| **CA-003** | Dado que el usuario navega entre módulos | cuando cambia de sección | entonces el sistema conserva la sesión sin recargar la aplicación completa | + | Pendiente |
| **CA-004** | Dado que la ventana se muestra en una pantalla de baja resolución | cuando se abre la aplicación | entonces el menú y el contenido siguen siendo utilizables sin desplazamiento horizontal | + | Pendiente |

**Cantidad de criterios: 4.**

## 4 · Notas

Los puestos de La Central son equipos de escritorio de resolución media. La aplicación es de gestión interna, no un sitio público: no se contemplan requisitos de posicionamiento ni de acceso desde dispositivos móviles.

## 1 · Historia

**Como** Vendedor  
**Quiero** consultar los clientes registrados  
**Para** verificar sus datos antes de operar con ellos

## 2 · Precondiciones

Existen clientes cargados en el sistema (HU-CLI-01)

## 3 · Criterios de aceptación

| ID | Dado que | Cuando | Entonces | Tipo | Prueba |
|---|---|---|---|---|---|
| **CA-001** | Dado que existen dos clientes con la misma Razón Social | cuando el vendedor busca por Razón Social | entonces el sistema devuelve ambos resultados en una lista | + | Pendiente |
| **CA-002** | Dado que existe un cliente con el CUIT/CUIL buscado | cuando el vendedor busca por CUIT/CUIL | entonces el sistema devuelve exactamente un resultado | + | Pendiente |
| **CA-003** | Dado que no existe ningún cliente que coincida con la búsqueda | cuando el vendedor ejecuta la búsqueda | entonces el sistema muestra el mensaje «sin resultados» y no una pantalla vacía | − | Pendiente |
| **CA-004** | Dado que existen clientes activos e inactivos que coinciden | cuando el vendedor busca sin habilitar la opción de inactivos | entonces el sistema devuelve únicamente los clientes activos | + | Pendiente |
| **CA-005** | Dado que el cliente tiene varios teléfonos y direcciones | cuando el vendedor abre su detalle | entonces el sistema muestra la totalidad de sus teléfonos y direcciones | + | Pendiente |

**Cantidad de criterios: 5.**

## 4 · Notas

La opción de incluir inactivos debe ser explícita y estar visible en el formulario de búsqueda.

## 1 · Historia

**Como** Encargado de Administración  
**Quiero** consultar las facturas de compra registradas  
**Para** verificar qué se compró, a qué proveedor y a qué precio

## 2 · Precondiciones

Existen facturas de compra registradas (HU-FCO-01)

## 3 · Criterios de aceptación

| ID | Dado que | Cuando | Entonces | Tipo | Prueba |
|---|---|---|---|---|---|
| **CA-001** | Dado que existe una factura con ese número para ese proveedor | cuando el usuario busca por número y proveedor | entonces el sistema devuelve exactamente una | + | Pendiente |
| **CA-002** | Dado que el proveedor tiene varias facturas | cuando el usuario busca por proveedor | entonces el sistema devuelve la lista completa | + | Pendiente |
| **CA-003** | Dado que el usuario define un rango de fechas de emisión o vencimiento | cuando se ejecuta la búsqueda | entonces el sistema devuelve solo las comprendidas en ese rango | + | Pendiente |
| **CA-004** | Dado que no hay coincidencias | cuando se ejecuta la búsqueda | entonces el sistema muestra el mensaje «sin resultados» | − | Pendiente |
| **CA-005** | Dado que existen facturas anuladas entre los resultados | cuando se consulta el listado | entonces el sistema las muestra marcadas como anuladas | + | Pendiente |

**Cantidad de criterios: 5.**

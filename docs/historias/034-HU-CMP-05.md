## 1 · Historia

**Como** Vendedor  
**Quiero** abrir la página del proveedor desde el comparador  
**Para** verificar la información en la fuente cuando lo necesito

## 2 · Precondiciones

El proveedor tiene URL de referencia cargada en su ficha (HU-PRO-01)

## 3 · Criterios de aceptación

| ID | Dado que | Cuando | Entonces | Tipo | Prueba |
|---|---|---|---|---|---|
| **CA-001** | Dado que el proveedor tiene URL de referencia cargada | cuando se muestra el comparador | entonces el sistema ofrece la opción de abrir su sitio | + | Pendiente |
| **CA-002** | Dado que el proveedor no tiene URL cargada | cuando se muestra el comparador | entonces el sistema no muestra la opción de redirección para ese proveedor | − | Pendiente |
| **CA-003** | Dado que el vendedor abre el sitio del proveedor | cuando se produce la redirección | entonces el sistema conserva la pantalla del comparador sin perder la búsqueda en curso | + | Pendiente |

**Cantidad de criterios: 3.**

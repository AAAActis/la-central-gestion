## 1 · Historia

**Como** Usuario del sistema  
**Quiero** ingresar mis credenciales desde una pantalla propia  
**Para** acceder al sistema con la identidad de mi puesto de trabajo

## 2 · Precondiciones

La API expone el endpoint de autenticación (HU-ACC-01)

## 3 · Criterios de aceptación

| ID | Dado que | Cuando | Entonces | Tipo | Prueba |
|---|---|---|---|---|---|
| **CA-001** | Dado que las credenciales son correctas | cuando el usuario confirma el ingreso | entonces el sistema lo redirige a la pantalla principal | + | Pendiente |
| **CA-002** | Dado que las credenciales son incorrectas | cuando el usuario confirma el ingreso | entonces el sistema muestra un mensaje genérico que no revela si falló el usuario o la contraseña | − | Pendiente |
| **CA-003** | Dado que la API no responde | cuando el usuario intenta ingresar | entonces el sistema informa que no hay conexión con el servidor, sin exponer detalles técnicos | − | Pendiente |
| **CA-004** | Dado que el usuario dejó un campo vacío | cuando intenta confirmar | entonces el sistema bloquea el envío e indica el campo faltante | − | Pendiente |

**Cantidad de criterios: 4.**

## 4 · Notas

El mensaje de error genérico replica el criterio de HU-ACC-01, CA2: no debe revelarse cuál de los dos datos falló.

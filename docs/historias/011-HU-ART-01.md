## 1 · Historia

**Como** Encargado de Reposición  
**Quiero** dar de alta un artículo junto con los códigos que le asigna cada proveedor  
**Para** poder identificarlo en las facturas de cualquier proveedor y compararlo en el buscador

## 2 · Precondiciones

Existen proveedores activos a los que asociar los códigos (HU-PRO-01)

## 3 · Criterios de aceptación

| ID | Dado que | Cuando | Entonces | Tipo | Prueba |
|---|---|---|---|---|---|
| **CA-001** | Dado que no existe ningún artículo con el código interno ingresado | cuando el usuario confirma el alta | entonces el sistema registra el artículo en estado activo con existencia cero en ambas ubicaciones | + | Pendiente |
| **CA-002** | Dado que ya existe un artículo con ese código interno | cuando el usuario intenta confirmar | entonces el sistema rechaza el alta e informa a qué artículo pertenece el código | − | Pendiente |
| **CA-003** | Dado que el usuario carga un solo código alternativo | cuando el usuario confirma el alta | entonces el sistema lo registra: no existe una cantidad mínima obligatoria de códigos | + | Pendiente |
| **CA-004** | Dado que el código alternativo ingresado ya está asignado a otro artículo | cuando el usuario intenta agregarlo | entonces el sistema lo rechaza e informa el artículo al que pertenece | − | Pendiente |
| **CA-005** | Dado que el usuario agrega un código alternativo sin indicar proveedor | cuando el usuario intenta confirmar | entonces el sistema bloquea la operación: todo código pertenece a un proveedor | − | Pendiente |
| **CA-006** | Dado que el usuario cargó los márgenes de venta | cuando el usuario confirma el alta | entonces el sistema los registra y quedan disponibles para el cálculo del precio estimado | + | Pendiente |

**Cantidad de criterios: 6.**

## 4 · Notas

HU fundacional: sin códigos alternativos por proveedor no funcionan HU-FCO-05 ni HU-CMP-01. Regla confirmada: un código pertenece a un único artículo; un artículo puede tener varios códigos.

## 1 · Historia

**Como** Encargado de Administración  
**Quiero** consultar los proveedores registrados  
**Para** verificar sus datos y acceder a su información de contacto

## 2 · Precondiciones

Existen proveedores cargados (HU-PRO-01)

## 3 · Criterios de aceptación

| ID | Dado que | Cuando | Entonces | Tipo | Prueba |
|---|---|---|---|---|---|
| **CA-001** | Dado que existen varios proveedores con Razón Social similar | cuando el usuario busca por Razón Social | entonces el sistema devuelve todos los coincidentes en una lista | + | Pendiente |
| **CA-002** | Dado que existe un proveedor con el CUIT buscado | cuando el usuario busca por CUIT | entonces el sistema devuelve exactamente un resultado | + | Pendiente |
| **CA-003** | Dado que no hay coincidencias con el criterio de búsqueda | cuando el usuario ejecuta la búsqueda | entonces el sistema muestra el mensaje «sin resultados» | − | Pendiente |
| **CA-004** | Dado que existen proveedores inactivos que coinciden | cuando el usuario busca sin habilitar inactivos | entonces el sistema los excluye del resultado | + | Pendiente |
| **CA-005** | Dado que el proveedor tiene URL de referencia cargada | cuando el usuario abre su detalle | entonces el sistema muestra sus teléfonos, direcciones y la URL | + | Pendiente |

**Cantidad de criterios: 5.**

## 1 · Historia

**Como** Encargado de Administración  
**Quiero** consultar los proveedores registrados  
**Para** verificar sus datos y acceder a su información de contacto

## 2 · Precondiciones

Existen proveedores cargados (HU-PRO-01)

## 3 · Criterios de aceptación

| ID | Dado que | Cuando | Entonces | Tipo | Prueba |
|---|---|---|---|---|---|
| **CA-001** | Dado que existen varios proveedores con Razón Social similar | cuando el usuario busca por Razón Social | entonces el sistema devuelve todos los coincidentes en una lista | + | Pendiente |
| **CA-002** | Dado que existe un proveedor con el CUIT buscado | cuando el usuario busca por CUIT | entonces el sistema devuelve exactamente un resultado | + | Pendiente |
| **CA-003** | Dado que no existe ningún proveedor que coincida con la búsqueda | cuando se ejecuta la búsqueda | entonces el sistema responde con éxito una página vacía, con la misma forma que una página con resultados (total 0, página y tamaño), y la pantalla muestra «sin resultados» | − | Pendiente |
| **CA-004** | Dado que existen proveedores inactivos que coinciden | cuando el usuario busca sin habilitar inactivos | entonces el sistema los excluye del resultado | + | Pendiente |
| **CA-005** | Dado que el proveedor tiene URL de referencia cargada | cuando el usuario abre su detalle | entonces el sistema muestra sus teléfonos, direcciones y la URL | + | Pendiente |

**Cantidad de criterios: 5.**

| v1.1 | 05/11/2026 | Equipo (decisión de Santi del 05/11; redactó el agente) | CA-003 v1.0: «Dado que no hay coincidencias con el criterio de búsqueda | cuando el usuario ejecuta la búsqueda | entonces el sistema muestra el mensaje “sin resultados”». Al paginar la búsqueda (#147), «sin resultados» deja de ser un 404 y pasa a ser 200 con una página vacía. Motivo: una búsqueda sin coincidencias es una consulta exitosa; el 404 afirma que la colección no existe, y si la pantalla lo trata como «sin resultados», un 404 real (ruta mal escrita, endpoint movido) deja de detectarse. La respuesta vacía lleva la misma envoltura que la llena, para que el listado dibuje el estado vacío sin casos especiales por endpoint.

## 1 · Historia

**Como** Encargado de Administración  
**Quiero** ver el precio de lista y el bonificado de cada proveedor  
**Para** decidir a qué proveedor conviene comprarle el repuesto

## 2 · Precondiciones

El comparador devolvió resultados para el artículo (HU-CMP-01)

## 3 · Criterios de aceptación

| ID | Dado que | Cuando | Entonces | Tipo | Prueba |
|---|---|---|---|---|---|
| **CA-001** | Dado que el proveedor publica precio de lista y precio bonificado | cuando se muestra la vista Compra | entonces el sistema despliega ambos valores | + | Pendiente |
| **CA-002** | Dado que hay varios proveedores comparados | cuando se muestra la vista Compra | entonces el sistema indica la diferencia de cada uno respecto de la opción más barata | + | Pendiente |
| **CA-003** | Dado que el artículo tiene un último proveedor comprado registrado | cuando se muestra la vista Compra | entonces el sistema lo señala como referencia | + | Pendiente |
| **CA-004** | Dado que un proveedor publica un único precio | cuando se muestra la vista Compra | entonces el sistema lo muestra aclarando que ese proveedor no informa precio bonificado | − | Pendiente |

**Cantidad de criterios: 4.**

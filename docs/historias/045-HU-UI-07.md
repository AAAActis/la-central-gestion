## 1 · Historia

**Como** Vendedor o encargado de compras  
**Quiero** administrar clientes y proveedores desde la interfaz  
**Para** operar sobre ellos sin depender de herramientas técnicas de base de datos

## 2 · Precondiciones

HU-UI-04, HU-UI-05 y HU-UI-06 implementadas · Épicas 1 y 2 disponibles en la API

## 3 · Criterios de aceptación

| ID | Dado que | Cuando | Entonces | Tipo | Prueba |
|---|---|---|---|---|---|
| **CA-001** | Dado que el usuario abre el módulo | cuando se carga la pantalla | entonces el sistema permite consultar, dar de alta, modificar y dar de baja | + | Pendiente |
| **CA-002** | Dado que el registro tiene varios teléfonos y direcciones | cuando se abre su detalle | entonces el sistema los muestra todos y permite administrarlos por separado | + | Pendiente |
| **CA-003** | Dado que el proveedor tiene URL de referencia cargada | cuando se abre su ficha | entonces el sistema muestra la dirección y permite abrirla | + | Pendiente |
| **CA-004** | Dado que se intenta dar de alta un CUIT ya existente | cuando el usuario guarda | entonces el sistema muestra el rechazo devuelto por la API | − | Pendiente |

**Cantidad de criterios: 4.**

## 4 · Notas

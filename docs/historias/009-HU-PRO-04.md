## 1 · Historia

**Como** Encargado de Administración  
**Quiero** dar de baja un proveedor con el que ya no se opera  
**Para** sacarlo de las búsquedas y del comparador conservando el historial de compras

## 2 · Precondiciones

El proveedor existe y está activo

## 3 · Criterios de aceptación

| ID | Dado que | Cuando | Entonces | Tipo | Prueba |
|---|---|---|---|---|---|
| **CA-001** | Dado que el usuario reescribió correctamente el CUIT e ingresó el motivo | cuando el usuario confirma la baja | entonces el sistema marca el proveedor como inactivo conservando su historial | + | Pendiente |
| **CA-002** | Dado que el CUIT reescrito no coincide | cuando el usuario intenta confirmar | entonces el sistema rechaza la operación | − | Pendiente |
| **CA-003** | Dado que el motivo de baja está vacío | cuando el usuario intenta confirmar | entonces el sistema bloquea la operación e indica que el motivo es obligatorio | − | Pendiente |
| **CA-004** | Dado que el proveedor está inactivo | cuando el usuario abre el comparador de precios de un artículo que ese proveedor comercializa | entonces el sistema no lo incluye entre las opciones comparadas | − | Pendiente |
| **CA-005** | Dado que el proveedor inactivo tiene facturas de compra históricas | cuando se consultan esas facturas | entonces el sistema muestra correctamente sus datos | + | Pendiente |

**Cantidad de criterios: 5.**

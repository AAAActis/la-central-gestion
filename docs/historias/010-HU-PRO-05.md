## 1 · Historia

**Como** Encargado de Administración  
**Quiero** reactivar un proveedor dado de baja  
**Para** volver a comprarle sin recargar sus datos

## 2 · Precondiciones

El proveedor existe en estado inactivo (HU-PRO-04)

## 3 · Criterios de aceptación

| ID | Dado que | Cuando | Entonces | Tipo | Prueba |
|---|---|---|---|---|---|
| **CA-001** | Dado que el proveedor está inactivo | cuando el usuario busca habilitando la opción de inactivos | entonces el sistema lo devuelve marcado como inactivo | + | Pendiente |
| **CA-002** | Dado que el usuario localizó el proveedor inactivo | cuando el usuario confirma la reactivación | entonces el sistema lo marca como activo y vuelve a estar disponible para facturas y comparador | + | Pendiente |
| **CA-003** | Dado que el proveedor fue reactivado | cuando se consulta su ficha | entonces el sistema conserva el motivo de la baja anterior | + | Pendiente |
| **CA-004** | Dado que el proveedor ya está activo | cuando el usuario intenta reactivarlo | entonces el sistema no ofrece la opción | − | Pendiente |

**Cantidad de criterios: 4.**

## 1 · Historia

**Como** Administrador  
**Quiero** dar de alta a un proveedor  
**Para** poder tener sus precios y tener trazabilidad de las operaciones que realizo con el.

## 2 · Precondiciones

El usuario cuenta con sesión iniciada (HU-ACC-01)

## 3 · Criterios de aceptación

| ID | Dado que | Cuando | Entonces | Tipo | Prueba |
|---|---|---|---|---|---|
| **CA-001** | Dado que no existe ningún proveedor con el CUIT ingresado | cuando el usuario confirma el alta | entonces el sistema registra el proveedor en estado activo | + | Pendiente |
| **CA-002** | Dado que ya existe un proveedor con el mismo CUIT | cuando el usuario intenta confirmar el alta | entonces el sistema rechaza la operación e informa el CUIT duplicado | − | Pendiente |
| **CA-003** | Dado que existe un proveedor con la misma Razón Social y distinto CUIT | cuando el usuario confirma el alta | entonces el sistema lo registra y muestra advertencia de posible duplicado | + | Pendiente |
| **CA-004** | Dado que el usuario ingresó una URL con formato inválido | cuando el usuario intenta confirmar el alta | entonces el sistema bloquea el guardado e indica que la URL no es válida | − | Pendiente |
| **CA-005** | Dado que el usuario no cargó URL de referencia | cuando el usuario confirma el alta | entonces el sistema registra el proveedor sin URL y el comparador no ofrecerá redirección para él | + | Pendiente |

**Cantidad de criterios: 5.**

## 4 · Notas

La URL de referencia alimenta HU-CMP-05. Es un campo opcional.

## 1 · Historia

**Como** Administrador  
**Quiero** que exista un rol operativo común y uno de administración  
**Para** que todos los puestos puedan trabajar sin trabas y solo la gestión de usuarios quede restringida

## 2 · Precondiciones

Existen usuarios cargados en el sistema (HU-ACC-02)

## 3 · Criterios de aceptación

| ID | Dado que | Cuando | Entonces | Tipo | Prueba |
|---|---|---|---|---|---|
| **CA-001** | Dado que un usuario tiene rol Operador | cuando accede al sistema | entonces el sistema le habilita clientes, proveedores, artículos, facturas, anulaciones, stock y comparador | + | Pendiente |
| **CA-002** | Dado que un usuario tiene rol Administrador | cuando accede al sistema | entonces el sistema le habilita todas las funciones operativas más la gestión de usuarios | + | Pendiente |
| **CA-003** | Dado que un Operador intenta acceder a la gestión de usuarios | cuando ejecuta la acción por vía directa | entonces el sistema la deniega, informa el motivo y no ejecuta ningún cambio | − | Pendiente |
| **CA-004** | Dado que un usuario tiene rol Operador | cuando se muestra el menú principal | entonces el sistema no despliega la opción de gestión de usuarios | − | Pendiente |

**Cantidad de criterios: 4.**

## 4 · Notas

Todos los puestos comparten los mismos permisos operativos porque quien atiende el mostrador también carga facturas de compra. Solo se distingue el rol de administración.

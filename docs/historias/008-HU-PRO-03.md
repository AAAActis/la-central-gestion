## 1 · Historia

**Como** Encargado de Administración  
**Quiero** modificar los datos de un proveedor  
**Para** mantener actualizado su contacto y la dirección de su página de precios

## 2 · Precondiciones

El proveedor existe y está activo (HU-PRO-01)

## 3 · Criterios de aceptación

| ID | Dado que | Cuando | Entonces | Tipo | Prueba |
|---|---|---|---|---|---|
| **CA-001** | Dado que el proveedor está activo y los datos son válidos | cuando el usuario guarda los cambios | entonces el sistema actualiza el registro | + | Pendiente |
| **CA-002** | Dado que el CUIT ingresado ya pertenece a otro proveedor | cuando el usuario intenta guardar | entonces el sistema rechaza el cambio e informa el conflicto | − | Pendiente |
| **CA-003** | Dado que el usuario modifica únicamente la URL de referencia | cuando el usuario guarda | entonces el sistema actualiza la URL sin alterar el resto de los datos | + | Pendiente |
| **CA-004** | Dado que el proveedor está dado de baja | cuando el usuario intenta modificarlo | entonces el sistema deniega la operación e indica que debe reactivarse | − | Pendiente |

**Cantidad de criterios: 4.**
